# Настройки, данные и резервное копирование

[English](../en/settings-data-and-backup.md) | [Русский](settings-data-and-backup.md)

Settings открывается кнопкой с шестерёнкой. Поддерживаемый способ изменения
конфигурации — окно с формами. Выберите раздел, измените поля и нажмите
`Save section`; `Ctrl+S` сохраняет активный раздел, `Esc` закрывает окно. При
переходе с несохранёнными изменениями к другому разделу или закрытии появляется
запрос на их отмену.

В каждом разделе есть кнопка `?` с кратким описанием полей. Полный список
находится в [справочнике по Settings](../../help/ru/README.md).

`Open raw JSON` — запасной путь для продвинутого редактирования. Сначала
сохраните или отмените изменения формы, не удаляйте неизвестные свойства и
после внешней правки снова пройдите через сохранение Settings либо перезапустите
Pact. Не передавайте другим людям `agent-control.json` и `orchestrator.json`.

## Каталог данных

По умолчанию каталог данных — `%APPDATA%\Pact`. В нём ровно четыре каталога
верхнего уровня:

- `Settings` содержит постоянный JSON и проектные Notes;
- `WebView` содержит браузерные профили, cookies и данные сайтов;
- `Logs` содержит ограниченные по размеру временные диагностические логи;
- `Temp` содержит временные файлы сессий и управляемые владельцами кеши.

PACT:> не сохраняет расшифровки терминалов и журналы ревью. Восстановленная
история принадлежит внешнему агенту. Текущий экран терминала существует только
пока жив его процесс.

Параметр `--data-root <absolute-path>` создаёт отдельный профиль для проверки.
Прежде чем другой процесс откроет каталог данных, первый должен освободить его.

## Браузерные данные и приватность

Браузерные страницы используют общий постоянный профиль WebView2, поэтому
авторизация и данные сайтов переживают перезапуск. Терминальные страницы xterm
работают в отдельном временном профиле, очищаемом при запуске. Обычная очистка
удаляет старый дисковый кеш браузера, но сохраняет cookies, Local Storage,
IndexedDB, service workers, пароли, autofill и настройки.

Логи могут содержать обезличенные метаданные жизненного цикла и транспорта, но в
них не записываются промпты сценариев, ответы, экраны терминалов или текст
строки статуса. Перед прикреплением лога к обращению всё равно проверьте его на
приватные адреса, пути, сведения об аккаунте и другие личные данные.

## Безопасная резервная копия

Перед копированием профиля закройте Pact. Из каталога с исходниками запустите
утилиту профиля, указав пустой абсолютный каталог назначения:

```powershell
dotnet run --project tools/Pact.ProfileTool/Pact.ProfileTool.csproj -- --source "$env:APPDATA\Pact" --destination "D:\Backups\Pact"
```

Утилита копирует постоянные Settings и Notes, но не логи, состояние браузера и
временные файлы. Добавляйте `--replace` только если намеренно хотите заменить
существующий каталог назначения.
