# Рабочее пространство и сессии

[English](../en/workspace-and-sessions.md) | [Русский](workspace-and-sessions.md)

Левое дерево разделяет работу внутри проектов и независимые вкладки `ROOT`.
Выбор элемента меняет центральную область, но не останавливает остальные
запущенные терминальные процессы.

## Проекты

Каждый проект указывает на один каталог репозитория и владеет своими
сохранёнными терминальными сессиями, браузерными страницами, Notes, просмотром
проектных Markdown-файлов, Git-панелью и состоянием ревью. В карточке проекта
находятся действия для добавления терминалов и веб-страниц, открытия Git и
перехода к настройкам проекта.

Приостановка проекта останавливает его живые сессии, предварительно пытаясь
сохранить команды их восстановления. Проект исчезает из активного дерева; его
можно вернуть через меню в заголовке `PROJECTS`. Восстановление проекта не
создаёт незаметно новый диалог агента: сохранённая сессия использует собственную
команду восстановления, если она была получена, иначе возвращается к команде
запуска или правилу профиля.

При закрытии приложения Pact также пытается получить данные для восстановления
агентов, прежде чем остановить терминальные процессы. Сохранённая после
предыдущего запуска метка `Running` сама по себе не означает, что процесс всё
ещё существует.

## Сессии

Терминальная сессия — это видимый процесс с собственным экраном xterm.js и
встроенным ConPTY. Сессии продолжают работать, пока вы просматриваете другой
терминал, документ или браузерную страницу. Индикаторы в дереве различают
активную работу, вопрос, ожидающий ответа, непрочитанное завершение, паузу и
ошибку.

Через действие редактирования сессии можно изменить её название и команды
запуска или восстановления. Сессии агентов работают в каталоге своего проекта.
Для PowerShell и Custom можно указать отдельный рабочий каталог.

У проектных сессий нет отдельных действий Pause/Resume. Если у сохранённой
проектной сессии нет живого процесса, её выбор запускает сессию, предпочитая
команду восстановления. Чтобы отложить сразу все сессии проекта, приостановите
сам проект.

## ROOT

`ROOT` предназначен для постоянных терминалов и браузерных страниц, которые не
относятся к репозиторию. Действие `+` добавляет терминал, действие `@` —
веб-страницу. У каждого элемента ROOT есть собственные Pause/Resume; общей
приостановки или закрытия всего раздела нет. Выбор приостановленного элемента
ROOT его не запускает — используйте явное действие `Resume`.

Терминалы ROOT могут получать ручные промпты, вставку и действия с выделенным
текстом. Они не участвуют в проектных сценариях ревью и не владеют проектными
Notes, Markdown-файлами или состоянием Git.

Строки терминалов и браузеров можно перетаскивать внутри одного владельца и
типа. Изменение порядка не переносит элемент между проектами или в ROOT.
