# Браузер, Docs & Notes и Git

[English](../en/browser-docs-and-git.md) | [Русский](browser-docs-and-git.md)

Контекст проекта в PACT:> не ограничен терминалом. Сохранённые страницы
WebView2, Markdown-файлы, Notes и состояние Git остаются рядом с живыми
сессиями проекта.

## Браузерные страницы

Действие `@` на карточке проекта или ROOT создаёт страницу из настроенного
шаблона веб-ссылки. `Custom URL...` принимает точный абсолютный HTTP(S)-адрес.
Страницы сохраняют текущий URL и состояние браузерного профиля между запусками
приложения. Cookies и данные сайтов остаются в выбранном каталоге данных Pact.

Проектная страница без загруженного WebView загружается при выборе. У страниц
ROOT дополнительно есть отдельные действия Pause/Resume: Pause выгружает
WebView, но не удаляет сохранённую вкладку; выбор вручную приостановленной
страницы ROOT её не загружает. Для такой страницы используйте `Resume`.
Закрытие страницы удаляет сохранённую вкладку.

Веб-мониторинг работает только для страниц, WebView которых уже был загружен.
Страницей управляет первое включённое правило с подходящим шаблоном URL.
В Settings замените все стартовые значения-заглушки, выполните
`Test on current tab` и только затем включайте правило. Скрытая загруженная
страница продолжает опрос; выгруженная страница, включая вручную
приостановленную страницу ROOT, — нет.

Когда наблюдаемая страница меняется в фоне, в дереве появляется непрочитанный
индикатор. Просмотр страницы в активном видимом окне Pact подтверждает
изменение. Поля правил и расписание описаны в разделе
[Правила веб-мониторинга](../../help/ru/settings-web-monitoring-rules.md).

## Docs & Notes

Псевдовкладка проекта `Docs & Notes` содержит три группы:

- `Notes` — принадлежащий приложению блокнот проекта;
- `Common MD's` — Markdown-файлы вне каталога `docs` репозитория;
- `Docs` — полное дерево `docs`.

Notes по умолчанию открывается в Editor, проектные файлы — в Preview. Для
смены режима служит явный переключатель `Preview | Editor`. Проектный Markdown
редактируется на месте и сохраняется атомарно.

Если файл на диске изменился, пока в редакторе были несохранённые изменения,
Pact не перезаписывает ни одну из версий. `Reload from disk` отбрасывает
локальное изменение, а `Save mine` намеренно заменяет версию на диске. Чистый
открытый документ автоматически перечитывается после внешнего изменения.

## Git-попап

Действие `⎇` на карточке Git-проекта открывает Git-попап. Он читает состояние
репозитория отдельными процессами Git и показывает удалённый адрес, ветку,
ahead/behind, счётчики рабочего дерева, журнал операций и основные действия.
Git-команды не отправляются через терминал агента.

Stash, pop, resolve и abort видны только тогда, когда применимы. Необязательные
внешние инструменты вроде TortoiseGit настраиваются в
`Settings > Git helpers`; недоступные инструменты остаются скрытыми.
