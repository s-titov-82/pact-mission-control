# PACT:> Mission Control branding

## Name

**PACT:> Mission Control**

- **P** — Projects
- **A** — Agents
- **C** — Contexts
- **T** — Tasks

The `:>` mark combines a terminal prompt, a direction of action, and a
commanded trajectory. The full Russian lockup is **ПАКТ:> ЦУП**.

Use `PACT:>` or `PACT:> Mission Control` in user-facing text. `Pact` remains
the internal namespace, assembly prefix, and `%APPDATA%\Pact` runtime directory
name.

## pact.io disambiguation

[pact.io](https://pact.io) is an established contract-testing project. This
product therefore uses both the `:>` mark and the `Mission Control` descriptor
instead of presenting itself as bare “Pact”. The categories and visual identity
are different, but that product choice is not a trademark opinion.

The [dated public-name search](name-collision-search-2026-07-29.md) records the
queries and limitations considered before selecting the repository slug. It
does not establish legal availability or permanent uniqueness.
