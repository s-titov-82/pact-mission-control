# Общий дашборд ROOT и навигация после закрытия

Статус: согласовано пользователем 2026-11-03; реализовано 2026-11-04.
Сборка, локальные тесты, рендер настоящего view, native WebView и мягкий
перезапуск проверены. Итоговое внешнее ревью кода ожидает разрешения на
передачу полного diff Claude Opus через Pact. Изменения не закоммичены.

## Назначение

Дать общий обзор открытых проектов и предсказуемую точку возврата после
закрытия вкладки или паузы проекта. Переход к обзору не должен запускать
соседнюю сохранённую сессию и не должен останавливать фоновые процессы.

## Согласовано в обсуждении

- Карточки открытых проектов: название, запущенные агенты и их текущие
  состояния, наличие ожидающих изменений.
- Клик по названию проекта открывает Overview; по агенту — его сессию;
  по сводке изменений — Changes.
- Закрытие выбранной вкладки проекта возвращает в Overview этого проекта.
- Закрытие выбранной вкладки ROOT возвращает на общий дашборд.
- Закрытие или пауза текущего проекта возвращает на общий дашборд.
- Закрытие фоновой вкладки или проекта сохраняет текущий экран.
- Запуск восстанавливает прежний экран; если восстанавливать нечего,
  показывает общий дашборд.
- Общий дашборд открывается кликом по плашке ROOT, аналогично экрану проекта.
  Отдельной кнопки «Домой» нет.

## Подходы

Выбран общий экран с компактными карточками на существующих данных проектов,
сессий и Git. Точка входа — уже существующая плашка ROOT. Это сохраняет
аналогию с проектом и не добавляет отдельный элемент навигации.

Отдельная кнопка «Домой» была предложена и заменена пользователем на ROOT.
Отдельный каталог проектов с собственной копией статусов не нужен: состав
проектов и сессий уже принадлежит MainWindowViewModel, а состояния агентов —
существующим SessionViewModel и runtime-координатору.

## Состав экрана

Предлагаемые детали реализации (решения исполнителя, не отдельные требования
пользователя):

- Карточки идут в порядке открытых проектов в дереве. Приостановленные
  проекты не включаются. Проект без запущенных агентов остаётся виден.
- Название и заголовок карточки ведут в Overview. Вложенные действия
  сессии и Changes не вызывают одновременно переход в Overview.
- Строка агента показывает название сессии, вид агента и существующее
  состояние/индикатор, включая unread, запрос ввода, ошибку и Read later.
  Это проекция существующих фактов, без второго классификатора.
- В список агентов входят сессии, у которых действительно есть живой
  runtime; сохранённый Running сам по себе недостаточен. Обычные shell и
  браузерные вкладки в этот список не включаются. Во время запуска/остановки
  строка использует фактическое переходное состояние, когда runtime уже есть.
- «Ожидающие изменения» в первом варианте означают незакоммиченные изменения
  рабочего дерева: staged, unstaged и untracked. Файл учитывается один раз.
  Неотправленные коммиты и статус CI сюда не входят.
- Сводка: Changes · N либо No uncommitted changes. Для проекта без Git
  блока Changes нет. До первой проверки — Checking changes; при ошибке —
  Changes unavailable, а не ложное отсутствие изменений.
- Когда открытых проектов нет, экран сообщает об этом и предлагает
  существующее действие открытия/добавления проекта. ROOT-сессии остаются
  доступны в дереве; глобальный оркестратор не является карточкой проекта.
- Карточки переносятся по ширине и прокручиваются по вертикали; применяются
  существующие цвета, шрифты и состояния фокуса. Тексты интерфейса — английские.

## Навигация и восстановление

- Дашборд — явное состояние показываемой поверхности, а не значение None
  с возможным неявным возвратом к выбранной сессии или браузеру.
- Плашка ROOT получает текущую подсветку, когда показан дашборд. Раскрытие
  стрелкой остаётся отдельным действием. Кнопки добавления терминала и
  браузера не открывают дашборд побочно.
- Переход на дашборд снимает выбор конкретной сессии/веб-вкладки/проекта
  и отключает адресованные им действия, но не очищает их состояние и unread.
- Навигация не подтверждает непрочитанные ответы и не снимает Read later.
  Выбор агента из карточки использует обычную активацию с её правилами чтения.
- Пауза отдельного ROOT-элемента сохраняет существующий Paused placeholder;
  новый переход относится к закрытию вкладки, а не к её паузе.
- Переход после закрытия выполняется, только если закрывается текущий
  контекст и пользователь не выбрал другой экран за время асинхронной операции.
  Захват resume-команды и поздние callbacks не должны менять новый выбор.
  В реализации захват при паузе проекта вообще не меняет показанную сессию;
  существующий показ терминала при завершении приложения сохранён.
- Возврат в Overview выбирает именно эту проектную вкладку и сохраняет её
  обычным механизмом; соседняя сессия не выбирается и не запускается.
- Выбор дашборда входит в общий startup checkpoint и soft-restart snapshot.
  ROOT остаётся владельцем только собственных вкладок: дашборд не получает
  project id, Notes, Git-контекст или права MCP от какого-либо проекта.
- Некорректный или исчезнувший восстановленный выбор приводит на дашборд.
  Ранее активные процессы восстанавливаются существующим механизмом;
  выбор дашборда сам не запускает дополнительные сессии.

## Обновление данных и владение

Статусы агентов обновляются существующими событиями. Подписки на карточки
снимаются при удалении/паузе проекта и освобождении экрана.

Git использует существующие runner и parser рабочего дерева, без загрузки
диффов всех проектов. Для карточек достаточно status и количества уникальных
путей; существующий ReadChangesAsync дополнительно читает numstat, поэтому
его полную загрузку не следует умножать на все проекты ради одного счётчика.
Допустимо выделить лёгкое чтение сводки в существующем Git reader.
Проверки нужны, пока дашборд показан, с ограниченной частотой
(ориентир — существующий интервал сверки Changes 5 секунд) и не более двух
одновременных Git-процессов для карточек. Скрытие экрана прекращает новые
проверки. Повторная проверка одного проекта не перекрывает предыдущую;
результат старого корня или поколения экрана не публикуется после смены
корня, паузы или удаления. Нельзя создавать второй наблюдатель рабочего
дерева только ради карточки; использовать доступный общий результат или
общий reader с ограниченным жизненным циклом.

Presentation владеет проекцией карточек; App/Avalonia — отображением,
связыванием ROOT и переходами между PresentedSurface. Существующие
персистентные записи остаются источником состава проектов и вкладок.

## Границы

В этот этап не входят канбан, pact_report, история событий, счётчик unread
у проектов, новые харнессы, расширение Overview, новые MCP-инструменты,
просмотр отдельного коммита и исправление Ctrl+V.

## Проверка результата

- Карточки отражают открытие/паузу/закрытие проектов и живые состояния агентов.
- Ошибка Git, отсутствие репозитория, пустое и изменённое дерево различимы;
  смена корня и уход с экрана защищены от поздних результатов.
- ROOT открывает дашборд; раскрытие и вложенные кнопки сохраняют свои действия.
- Закрытие текущего терминала/веб-вкладки проекта ведёт в Overview; ROOT —
  на дашборд. Закрытие/пауза текущего проекта ведёт на дашборд.
- Закрытие фонового контекста и позднее завершение операции не меняют новый
  экран пользователя. Навигация не запускает соседнюю сессию.
- Явно выбранный дашборд сохраняется при обычном и мягком перезапуске;
  отсутствующий выбор также приводит на него. Unread и Read later сохраняются.
- Проверяются ROOT pause placeholder, фоновые процессы, активные ревью,
  документы с несохранёнными правками и границы native WebView видимости.

Дизайн и последующий план коммитятся только вместе с реализацией.
