# Внешний вид

На вкладке **General** выберите **System** для темы Windows, **Light** для
светлой темы или **Dark** для тёмной. В списках вкладок ROOT и проектов флажок
**Show favicons** отвечает за значки сайтов, а **Show agent icons** — за логотипы
агентов. Изменения применяются сразу после нажатия **Save section**.

На вкладке Terminal theme выберите профиль Windows Terminal. В образце сразу
появятся его шрифт и цвета. Их можно изменить перед нажатием Save section.

На вкладке **Notifications** включите **Show Windows notifications**,
чтобы получать баннер при новом вопросе, ошибке или непрочитанном обновлении.
Щелчок по баннеру открывает соответствующую вкладку. В поле **Sound** можно
выбрать тишину, системный звук Windows, короткий сигнал в стиле «Аськи»
или три ноты перед вокзальным объявлением.

По умолчанию время показа определяет Windows (**Use Windows settings**).
Чтобы баннер оставался на экране до щелчка или закрытия, выберите
**Keep until dismissed**. Свой интервал в секундах можно задать в режиме
**Hide after a custom interval**. Скрытый баннер остаётся в центре уведомлений,
пока вкладка требует внимания.

На вкладке **PACT Dev Tools** можно показать или скрыть диагностику выбранной
вкладки под Quick actions и включить сбор данных об использовании процессора и
памяти для выбранного запущенного терминала или загруженной веб-вкладки.
