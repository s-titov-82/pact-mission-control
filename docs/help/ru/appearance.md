# Внешний вид

Выберите **System**, чтобы использовать тему Windows, либо принудительно
включите светлую (**Light**) или тёмную (**Dark**) тему приложения. Отображение
диагностики выбранной вкладки под Quick actions можно отключить независимо, а
метрики внешних процессов — включить отдельно. Пока эта опция выключена, сбор
метрик внешних процессов не выполняется. Сохранённые настройки применяются
сразу.
