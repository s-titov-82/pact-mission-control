# Недавние директории

Этот список наполняет подсказки директорий, показываемые в диалоге выбора директории для новой сессии в главном окне; больше нигде он не используется.

При сохранении записи нормализуются: каждая строка обрезается, пустые строки отбрасываются, дубликаты удаляются без учёта регистра, а список ограничивается 20 записями — всё, что превышает первые 20 после удаления дубликатов, отбрасывается. Кнопка «Add directory» добавляет выбранную папку новой строкой; при сохранении применяется та же нормализация.

По одному пути директории на строку.
