# Правила веб-мониторинга

Каждое правило сопоставляет загруженные веб-вкладки со своим URL-шаблоном и
опрашивает страницу через декларативные DOM-экстракторы. Правила проверяются по
порядку в файле; первый включённый подходящий вариант становится владельцем
вкладки.

Необязательный экстрактор Activity сообщает, выполняется ли сейчас работа.
Необязательный экстрактор Revision читает стабильное значение, изменение
которого может пометить фоновую вкладку как непрочитанную. Каждый экстрактор
использует CSS-селектор и источник (`exists`, `count`, `text` или `attribute`);
для `text` и `attribute` можно применить регулярное выражение и группу захвата.

Два стартовых правила — отключённые примеры. Их хосты-заглушки используют
зарезервированный домен `.invalid`, поэтому такие правила нельзя включить без
изменений. Перед включением замените хост и проверьте селекторы на собственных
аутентифицированных страницах TeamCity или GitLab.

**Test on current tab** один раз проверяет редактируемое правило на текущей
загруженной веб-вкладке и показывает совпадение URL, activity, revision или
ошибку. Проверка не сохраняет раздел, не удаляет несохранённые изменения и не
меняет состояние работающего мониторинга.
