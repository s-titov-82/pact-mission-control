# Корневые вкладки

ROOT содержит терминалы и веб-вкладки, которые не принадлежат ни одному
проекту. Их параметры, последняя выбранная вкладка и индивидуальное состояние
паузы хранятся в `root-tabs.json`.

Здесь можно изменить заголовок терминала, рабочую директорию, команду запуска и
команду возобновления. В отличие от проектных агентских сессий, у каждого
ROOT-терминала явно задана рабочая директория; новые терминалы открываются в
существующей домашней директории пользователя Windows.

У веб-вкладки можно изменить заголовок и URL. Новый URL используется при
следующей загрузке страницы.

Pause и Resume остаются действиями отдельной строки в главном окне. Выбор
приостановленной строки не возобновляет её.
