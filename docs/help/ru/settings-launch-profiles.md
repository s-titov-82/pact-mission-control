# Шаблоны терминалов

Каждая вкладка — это один профиль запуска; каждый профиль становится одной кнопкой запуска в главном окне.

Command — это команда, которая запускает совершенно новую сессию для этого профиля. Resume command копируется в сессию как её начальная команда восстановления в момент создания этой сессии, но затем больше не используется: если собственный текст команды восстановления сессии не имеет распознаваемого вида (например, «codex resume <id>» или «claude --resume <id>»), восстановление сессии откатывается на собственную команду запуска сессии.

Pact сохраняет команду выбранного профиля и добавляет к запуску Codex и Claude инструкции, относящиеся к конкретной сессии. Claude получает их через встроенный аргумент --append-system-prompt; Codex — через значение developer_instructions уровня текущего запуска, которое переопределяет значение того же ключа, унаследованное от выбранного профиля конфигурации Codex.

Id, Command и Shell должны быть непустыми, а id — уникальными среди профилей — иначе кнопка «Save section» отклоняет весь файл и называет проблемный профиль.
