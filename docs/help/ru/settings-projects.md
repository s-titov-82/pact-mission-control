# Текущие проекты

Каждая вкладка — это один открытый сейчас (активный) проект. Изменение имени, корневого пути, заметок, GitLab repo id или TeamCity project id здесь применяется немедленно к работающему приложению — отдельного шага публикации для других окон не требуется.

Корневой путь влияет на будущие запуски сессий и на панель git; уже запущенная сессия сохраняет ту рабочую директорию, с которой она была запущена.

Строка сводки только для чтения над полями (id, статус, время создания/последней активности) отражает текущее состояние проекта во время выполнения и здесь не редактируется.

Под проектом перечислены все его сессии. У сессии можно редактировать заголовок, рабочую директорию, команду запуска и команду восстановления — кроме случая, когда сессия заблокирована выполняющимся сценарием: тогда появляется подсказка «Locked by a running scenario», и поля становятся недоступными для редактирования до завершения запуска. Поле рабочей директории скрыто для сессий-агентов (Codex, Claude, Hermes), которые всегда работают в директории проекта; оно применимо только к сессиям pwsh/custom.

В этом разделе нет кнопки удаления проекта. Проекты создаются открытием директории из главного окна и удаляются закрытием проекта там же — раздел «Настройки» редактирует только те проекты, которые сейчас открыты. Приостановленный проект редактируется в отдельном разделе «Приостановленные проекты», а не здесь.
