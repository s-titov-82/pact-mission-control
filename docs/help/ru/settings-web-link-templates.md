# Шаблоны веб-ссылок

Каждая вкладка — это один шаблон веб-ссылки; каждый шаблон становится пунктом
меню «@» как для проекта, так и для ROOT в главном окне.

Клик по пункту меню шаблона отображает его начальный URL с учётом настроек проекта и открывает результат как новую вкладку веб-страницы в приложении. Плейсхолдеры %gitLabRepoId% и %teamCityProjectId% подставляются из GitLab repo id и TeamCity project id проекта (редактируются в разделе «Проекты»); как только любой из них оказывается пустым у проекта, весь отображённый URL отбрасывается — безусловно, а не только когда больше нечего отображать — и вместо него открывается корень сайта шаблона (только схема и хост). Любое другое имя %placeholder% приводит к тому, что весь шаблон завершается ошибкой вместо открытия страницы.

Из ROOT шаблон без плейсхолдеров открывает точный URL. У ROOT нет идентификаторов
проекта, поэтому шаблон с %gitLabRepoId% или %teamCityProjectId% открывает корень
сайта этого шаблона.

Отображённый URL фиксируется один раз, в момент создания веб-страницы — он не обновляется позже при изменении id проекта. Чтобы получить новые значения, откройте новую веб-страницу из шаблона.

Start URL должен быть абсолютным URL http или https (после подстановки либо как запасной вариант — корень сайта), иначе клик завершается ошибкой вместо открытия страницы.
