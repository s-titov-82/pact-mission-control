# Приостановленные проекты

Каждая вкладка — это один приостановленный проект: проект, чьи сессии были закрыты и отложены, но который не был удалён. Редактирование работает точно так же, как в разделе «Текущие проекты»: имя, корневой путь, заметки, GitLab repo id, TeamCity project id, а также заголовок, рабочая директория, команда запуска и команда восстановления каждой сессии применяются немедленно к работающему приложению.

Здесь нет кнопки «+»: добавление проекта из директории всегда создаёт активный проект, поэтому для этого используется раздел «Текущие проекты» (или главное окно). Снятие проекта с паузы (возобновление) также выполняется из главного окна, а не из настроек.

Всё остальное — строка сводки только для чтения, подсказка о блокировке сессии, скрытое поле рабочей директории для сессий-агентов и отсутствие кнопки удаления — работает так же, как в разделе «Текущие проекты».
