# Профили ревью

Каждая вкладка — это профиль запуска только для ревьюера, который используется, когда агент просит Pact запустить ревью. Эти профили не появляются в обычном меню запуска проекта.

Для Claude и Codex можно выбрать модель и уровень усилий или оставить значения агента по умолчанию. Pact читает локальный каталог моделей Codex, имена моделей Claude и дополнительные варианты из его кеша. Сохранённая модель остаётся в списке, даже если исчезла из кеша. Для скриптов запуска и дополнительных флагов включите **Use a custom launch command**.

Если после перечитывания настроек изменился список профилей или видов ревью, Pact сообщает об этом подключённым агентам. Например, это происходит при переходе на встроенные настройки из-за ошибки в `scenarios.json`. Изменения файлов вступают в силу после перечитывания настроек или перезапуска Pact.

Id и Command должны быть непустыми, а id — уникальными. При сохранении раздела неизвестные поля JSON сохраняются.
