# Профили ревью

Каждая вкладка — это профиль запуска только для ревьюера, который используется, когда агент просит Pact запустить ревью. Эти профили не появляются в обычном меню запуска проекта.

Command содержит флаги модели и уровня усилий для ревьюера. Для типов Claude и Codex Pact подключает инструменты автоматически, используя аргументы, которые принимает соответствующий интерфейс командной строки; отдельная настройка профиля для этого не нужна.

Подключённые агенты получают уведомление перечитать id профилей ревью и id сценариев всякий раз, когда перезагрузка Settings меняет живой каталог, в том числе когда из-за повреждённого JSON сценариев включаются встроенные значения по умолчанию. Внешние изменения файлов вступают в силу только на границе перезагрузки Settings или после перезапуска приложения.

Id и Command должны быть непустыми, а id — уникальными. При сохранении раздела неизвестные поля JSON сохраняются.
